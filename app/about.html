A place for each memory.

A working city-map module for the AILT9019 travel-album project.

What works now

Explore 19 supported cities, filter/search in English or Chinese, select markers or the city list, and browse separate sample trip cards. Independent saved trip IDs determine visit counts and the 1 / 2–3 / 4+ brightness tiers. Demo edits persist in this browser.

What comes next

Photo uploads and card editing will connect to the local Python/SQLite backend. User-triggered cloud AI will draft memory text from the current trip only. The prototype does not upload photos, call AI, verify visits or provide navigation.

Try it

Choose Osaka, open “Try visit counting”, and add a sample visit. Edit a sample card: the count stays the same. Reload: the sample changes remain. Use “Reset sample album” to start over. All existing stories are fictional.

Data and privacy

The coastline and approximate city centres come from Natural Earth public-domain data. No third-party tiles, fonts, analytics or AI requests are made by this demo. Browser storage is a demo adapter, not a backup or the planned SQLite implementation.

Project record

Setup, proposed API contracts, data provenance and test evidence are in the private team repository (team/course access required). The map module is ready for team integration review; the full AI application is not complete.
