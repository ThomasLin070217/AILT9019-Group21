A place for each memory.

AILT9019 Group 21's working travel album.

What works now

In API mode, choose one of 19 supported cities, create a separate card for each trip, upload photos, edit memories and return to them after a restart. Each saved visit brightens an approximate city area; editing a card does not count as another visit. The bundled local map needs no map key.

Optional AI

Write with AI asks for confirmation before sending the selected trip's city, date, title, notes and sanitised photos to a configured cloud model. Its draft stays editable. An AI key is optional; the album still works without one. A live provider result and the full five-case human evaluation have not yet been verified on this integrated build.

Data and privacy

Trip records and sanitised uploads are stored locally in SQLite and media files. The default online map uses OpenFreeMap tiles; use ?mode=api&map=local for the bundled map. The offline coastline uses Natural Earth data and approximate city footprints use OpenStreetMap contributors. City highlighting represents user-entered trips, not independently verified travel.

Project record

The public repository includes setup instructions, data credits and test evidence. The project webpage source presents the recorded workflow.
