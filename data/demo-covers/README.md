# Example cover photographs

These two Osaka photographs are licensed example assets for the album layout. They do not depict our fictional trip events or belong to any team member. Photographer credits appear beside the photos and in the viewer. Exact sources, download URLs, license and hashes are in [SOURCES.json](SOURCES.json).

Downloaded at 960px under the [Unsplash License](https://unsplash.com/license). They are not CC0. Browser previews use the local files; no third-party image requests occur at runtime. CSS crops the card preview; the photo viewer displays the full downloaded image. No AI image generation or local pixel editing was performed.

The photos are a separate presentation fixture; `data/demo-trips.json` still has empty photo arrays and original fictional notes. Two fixed demo IDs select these covers in demo mode only. API mode uses actual same-origin `/media/` references. No sample cover is substituted for missing backend media. T01–T05 evaluation data is unchanged.
