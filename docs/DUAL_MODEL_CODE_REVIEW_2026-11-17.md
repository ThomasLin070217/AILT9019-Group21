# Qwen + MiniMax 独立代码复核及修复

日期：2026-11-17。审阅基线：`635b459409f94a209d37cf2c2ccf18dd64399b57`。

实际调用 `qwen3.8-flash` 与 `MiniMax-M2.5`，串行运行，各自使用独立的新请求、相同代码清单。没有传入聊天历史、另一模型结论、私有照片、运行数据库或密钥。输入哈希、模型返回名、用量和最终意见保存在 [证据目录](../tests/evidence/2026-11-17-dual-review/)。模型只做静态审查；下面的浏览器和后端验证由维护者另行执行。

两个模型提出 **13 项候选问题、5 项待验证假设**，不等于发现 13 个真实漏洞。复核后修复 6 项，其中有些是沿着模型线索发现的其他实际缺陷。范围主要为桌面版；没有重做移动端。

## 全部模型意见及裁定

| 模型编号 | 原优先级 | 原意见 | 复核结论 |
|---|---|---|---|
| Q-F1 | P2 | 任意坏照片尺寸读取失败导致整个相册打不开 | 误报：已有逐项 catch 和默认尺寸。实际坏图显示错误状态，关闭后页面解除 inert。 |
| Q-F2 | P2 | SVG 地名宽度估算导致边缘裁切/重叠 | 1280px 全图状态未发现可见标记的文字被横向裁切；特定缩放、拖拽、字体仍可能触发，保留观察，不声称全部组合已覆盖。 |
| Q-F3 | P2 | 快速切城市时异步 sessionStorage 写入覆盖草稿 | 所述机制不成立：写入同步且按城市/旅行键区分。另发现并修复真实的异步保存丢字 S1。 |
| Q-F4 | P3 | 相册异常后背景可能一直 inert | 未证实：已有销毁恢复、初始化失败 catch；正常和坏图关闭均恢复。没有穷举任意浏览器内部异常。 |
| Q-F5 | P3 | 851–1024px 相册固定侧栏造成横向溢出 | 代码已有断点/min-width 处理；本轮900/1024/1280px相册均无横向溢出。所有内容规模未穷举，保留作为视觉观察项。 |
| M-F1 | P1 | 680px 最小高度导致普通笔记本裁切 | 误读旧规则：后续桌面覆盖为 560px。1280×720 无溢出；900×600 页面可纵向滚动至 684px，并非内容被剪掉。 |
| M-F2 | P2 | 附近城市面板遮住缩放控件 | 未证实；桌面 CSS 面板右侧 78px、控件右侧 22px/宽44px，横向有12px间隔。未穷举全部缩放组合。 |
| M-F3 | P1 | 关闭标签页丢失幂等键而自动产生重复旅行 | 未证实自动重复：重开先 GET，不自动重发 POST；关闭标签页会丢失未保存草稿/待重试键是当前限制。不要把用户重新创建同内容旅行当成必然 bug。 |

| M-F6 | P2 | 固定照片底部留白浪费矮屏空间 | 原意见偏设计判断；实测发现相反的长说明覆盖图片问题 S5，已改为实际测量留白。 |

| M-F8 | P2 | 1024px 宽度下地图过窄 | 误报：忽略断点，实际侧栏220px、地图474px、记忆栏330px。 |

### 五项假设

- Q-H1：恶意 GeoJSON city_id 经 `setAttribute` 打破 HTML 造成 XSS。这个数据属性赋值不会重新解析 HTML，所述攻击机制不成立。
- Q-H2：DraftStore/移除表单造成 DOM 泄漏。DraftStore 存字符串，无持有 DOM 的证据；本轮未做长期堆分析。
- M-H1：照片重编码真的清除 EXIF。现有后端照片测试随完整套件通过；不能据此宣称所有未来编码器漏洞都不存在。
- M-H2：关闭标签页重试真的造成重复。见 M-F3；跨标签页、用户主动重复提交不在现有同标签页重试保证内。
- M-H3：地图是否必须 unsafe-eval。[Google Maps 官方 CSP 示例](https://developers.google.cn/maps/documentation/javascript/content-security-policy?hl=en)包含它，因此只保留明确 Google 模式例外；本地地图和照片查看器实测无需它。Google 的真实 Key 模式本轮未再次验证。

## 验证与限制

- Python：94 项通过（新增5个 Host/Origin/CSP 回归测试）。Node：25 项通过。
- 桌面尺寸：900×600、1024×768、1280×720、1440×900、1920×1080，无横向溢出。矮窗口保留正常纵向滚动。
- 实际隔离 FastAPI/SQLite 测试实例，使用虚构旅行和仓库测试照片，未修改用户旅行数据。
- AI 编辑界面竞态测试使用合成响应，**不计作真实云端 AI 质量评估**；真实云端调用仅用于此次两模型代码审查。
- 当前公开 Pages 仍是浏览器内的样例体验；后端仍是本机服务，不因 Host 校验而变成有认证的公网服务。不要把无认证后端直接暴露到互联网。
- CSP 修改由 Python 后端发送；GitHub Pages 不会继承该 HTTP 响应头。
- sessionStorage 草稿/幂等键只保证同标签页刷新与重试；关闭标签页后不保证恢复。
- 本次是针对性复核，不是完整渗透测试，也不能保证所有浏览器和数据规模都无问题。
