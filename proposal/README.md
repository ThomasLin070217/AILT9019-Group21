# Proposal

Use the official course template for the final submission. Keep proposal content and filenames anonymous: do not include team members' names, student IDs, or email addresses.

Before the draft deadline, complete:

1. Background: one primary user, one task, and the current pain point.
2. Pipeline: request → method → result, with a small diagram.
3. Evaluation: fixed test cases, a success threshold, and a fail-safe case.
4. Accessibility: first-run steps for a non-technical user.
5. Ethics: an explicit "does not" statement, risks, and mitigations.
6. Checkpoints: must-have and should-have features with a timeline.
